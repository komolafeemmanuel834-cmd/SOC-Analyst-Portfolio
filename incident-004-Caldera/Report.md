## Executive Summary
CALDERA is an open-source framework built on the MITRE ATT&CK framework, that is designed to run autonomous adversary emulation exercises efficiently. It enables users to emulate real-world attack scenarios and assess the effectiveness of their security defences.

In addition, it provides a modular environment for red team engagements, supporting red team operators for the manual execution of TTPs and blue teamers for automated incident response actions. Security analysts can leverage the CALDERA framework in different cases such as autonomous Autonomous Red Team Engagements, Manual Red Team Engagements and Autonomous Incident Response.

## Objectives
The objective of this investigation is to demonstrate how Caldera can be used to safely emulate adversary techniques mapped to the MITRE ATT&CK framework. The exercise aims to validate the effectiveness of security controls, identify detection gaps, and evaluate the organization’s ability to detect, investigate, and respond to simulated malicious activity manually and automatically.

The investigation also demonstrates how threat emulation can be used as part of a continuous security testing process, allowing security teams to move from emulating adversary behaviour to developing and validating effective detection capabilities.

## Scenario
An organization in the financial sector wants to evaluate its ability to detect and respond to post-compromise attacker activity within its Windows Active Directory environment. To achieve this, the security team uses MITRE CALDERA to emulate a threat actor that has gained access to a workstation through a compromised employee account.

The emulation begins with the deployment of a CALDERA manx agent on a domain-joined workstation representing the attacker's foothold within the network. From this system, the adversary conducts discovery activities to gather information about the host, logged-on users, domain structure, and available network resources. These actions are intended to mimic the reconnaissance phase commonly observed in real-world intrusions.

After establishing situational awareness, the attacker attempts to access credentials stored on the compromised system. Credential access techniques are executed to determine whether security controls can detect attempts to interact with sensitive processes and obtain authentication material. The objective is to assess the organization's visibility into activities associated with credential theft.

Using the information gathered during reconnaissance, the adversary then performs lateral movement to additional systems within the environment. The attacker targets administrative shares and remote management services to access a file server containing sensitive business documents. Once access is obtained, files are identified and collected to simulate data staging activities.

The exercise concludes with a controlled exfiltration simulation in which non-sensitive test files are transferred through the CALDERA command-and-control channel. Throughout the operation, security monitoring tools, endpoint detection solutions, and SIEM platforms are expected to generate alerts and logs that can be analyzed by the SOC team.

The primary goal of this scenario is to validate detection coverage across multiple stages of the MITRE ATT&CK framework, including Discovery, Credential Access, Lateral Movement, Collection, and Exfiltration. The results of the exercise provide insight into existing detection capabilities, identify visibility gaps, and support the improvement of threat detection and incident response processes.

While the adversary emulation was being conducted, the Blue Team was responsible for monitoring and analyzing the activity generated by the CALDERA operation. Their objective was to identify malicious behaviors, investigate alerts, and determine the scope and impact of the simulated attack.

The Blue Team monitored endpoint and system logs for evidence of suspicious process execution, command-line activity, account enumeration, and network reconnaissance. As the adversary progressed through the attack lifecycle, analysts correlated events to build an understanding of the attacker's actions and objectives.

Particular attention was given to discovery-related activities, unusual command execution, access to sensitive files, and simulated data exfiltration. By analyzing these events, the Blue Team was able to map observed activity to relevant MITRE ATT&CK techniques and assess the effectiveness of existing detection rules and monitoring capabilities.

The exercise also provided an opportunity to evaluate incident response procedures. Analysts practiced identifying indicators of compromise, investigating alerts, and documenting findings in a manner consistent with real-world security operations. Any gaps in visibility or detection identified during the exercise could then be used to improve logging configurations, SIEM correlation rules, and overall defensive readiness.

## Tools
* Caldera – Used to safely and repeatedly emulate adversary behaviour in a controlled environment for the purpose of validating security controls and detection capabilities.
* Powershell - used during the initial stages of the operation to download and execute the CALDERA agent on the target machine.
* MITRE ATT&CK Framework – Used to map the simulated adversary behaviour to relevant tactics and techniques, specifically Credential Dumping (T1003).
* Windows Event Logs – Used to review system and security events generated during the Atomic Red Team test and identify evidence of suspicious activity.
* Endpoint Detection and Response (EDR) – Used to monitor endpoint activity and determine whether the simulated credential dumping behaviour was detected and alerted on.
* Security Information and Event Management (SIEM) – Used to collect and analyze security logs from the environment, search for relevant activity, and determine whether detection rules generated alerts during the emulation exercise.
